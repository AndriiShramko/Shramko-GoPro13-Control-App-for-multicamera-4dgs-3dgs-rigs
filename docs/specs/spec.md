## MISSION

Заложить фундамент синхронизации ~100 GoPro HERO13 по USB для 4DGS-захвата: база API-доков в репо, рабочий USB-контур одной камеры, измерительный стенд (экран+звук) и первые ЧИСЛА (джиттер старта, дрейф ppm, пределы каналов измерения), методика + протокол Фазы 1. Правда проекта: **genlock невозможен** → ±1 кадр достигается «ресинк часов + триггер + обрезка на посте», субкадровая точность (1/10→1/100 кадра) — только измерением и компенсацией на посте.

## STOP/DONE Фазы 0 (все = факт; DONE засчитывается только если verify-скрипт проходит)

1. E0 connectivity-gate пройден (лог: wired_usb→200, /state JSON, клип скачан) — или blocker-отчёт с диагностикой.
2. `docs/api/` база с INDEX (USB control, запись, медиа, GPMF, Labs; у каждого дока источник+дата) + `old-repo-audit.md` (таблица переиспользовать/устарело).
3. CLI: discover / record start-stop ×10 подряд / download / meta — логи реальных прогонов с серийником и fw.
4. GPMF-пайплайн: парсер выбран и smoke-протестирован на реальном клипе (DEVC читается); семантика STMP прибита экспериментом против счётчика.
5. E1: N≥30, CSV + гистограмма + mean/σ/min/max (framing: относительные величины/джиттер).
6. E2: ≥20 мин, ppm + CI, тепло-лог без Hot-инцидентов, цепочка QPC↔кадры↔GPMF в отчёте.
7. E3: scanout/response монитора охарактеризованы @240fps; T_readout — честная low-confidence оценка или descope с обоснованием.
8. E4: стабильность аудиоканала (20 клапов за один визит оператора), взаимный джиттер аудио-vs-экран.
9. `docs/methodology/desync-measurement.md`: пределы каждого канала в мс и долях кадра (30/60/120 fps) + `docs/protocols/phase1-pairwise.md` + gate-пороги Ф0→Ф1.
10. SD-инвентарь снят ДО первой чистки; удаления только после download+checksum.
11. Labs-кейс оператору написан (что даст, риски, порядок — в конце фазы).
12. Ветка `research/usb-sync-experiments` запушена, в main ноль новых коммитов (`git log main..HEAD` в отчёте), pre-push hook стоит и проверен; Obsidian: проект+Daily+AGENT_INDEX+уроки; финальный отчёт оператору.

Аварийный STOP: USB-канал не поднимается после исчерпания задокументированных подходов → blocker-отчёт, коммит, стоп. Камера умерла физически → оператор.

## ЗВАТЬ ОПЕРАТОРА (только физика, батчить в один визит)

Направить/закрепить камеру на монитор (safe-zone), переключить USB Connection в меню камеры, выключить свет на полосные тесты, серия 20 клапов в кадре по инструкции, аккум/кнопка/кабель при отвале, вторая камера (Ф1), решение по Labs-прошивке (флеш = операторская операция).
