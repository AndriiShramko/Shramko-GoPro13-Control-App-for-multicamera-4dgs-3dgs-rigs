# Gate-пороги Фаза 0 → Фаза 1 (заданы ДО измерений, red-team #21)

Изменение порога после получения данных — только с письменным обоснованием в vault (не «подогнать под результат»).

| # | Метрика | Порог GO | Если НЕ пройдено |
|---|---|---|---|
| G1 | Джиттер старта записи по USB (E1, σ) | σ ≤ 2 кадра @30fps (≤66 мс) | стратегия «одновременный триггер + обрезка» остаётся (обрезка терпит секунды), но планирование дублей получает бОльшие поля; исследовать `!S`-отложенный старт Labs |
| G2 | Повторяемость дрейфа (E2 повторы) | расхождение ppm между прогонами < 5 ppm | per-take калибровка дрейфа обязательна (маркеры в начале И конце каждого дубля становятся жёстким требованием протокола съёмки) |
| G3 | Декодер счётчика на КАМЕРНОМ клипе | ≥ 99% кадров с валидным idx (после наведения) | улучшать стенд (размер ячеек/контраст/выдержка) до порога; эксперименты не считаются |
| G4 | Автоматизация цикла | record→download→analyze без ручных шагов (кроме одноразовой физики) | чинить до перехода: на 100 камерах ручные шаги не масштабируются |
| G5 | Термостабильность | E2 (≥20 мин, 1080p30) без Hot-флага | пересмотр профиля длинных записей (питание/обдув/разрешение) до Ф1 |

Пороги достижимости целей проекта (для Ф1-Ф2, фиксируем уже сейчас):
- «±1 кадр» считается доказанным, когда P5-пайплайн даёт |Δ| ≤ 1 кадр на контрольной вспышке конца дубля в ≥ 9/10 дублей.
- «1/10 кадра» — контрольная вспышка после ретайминга ≤ 3.3 мс @30fps в ≥ 8/10.
- «1/100 кадра» — только при LED-канале с подтверждённой σ ≤ 0.3 мс; иначе честно фиксируем достигнутый предел.
