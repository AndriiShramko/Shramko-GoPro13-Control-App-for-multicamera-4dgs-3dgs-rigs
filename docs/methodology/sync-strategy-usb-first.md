# Стратегия синхронизации: USB-first (вводная оператора 2026-07-12)

**Констрейнт Андрия:** на площадке нереально показать QR всем 100 камерам; всё должно делаться по USB-кабелю. QR — только лабораторный инструмент стенда, НЕ операционная процедура съёмки.

## Что это меняет (честно, по фактам из docs/api)

1. **Стоковая прошивка по USB НЕ умеет миллисекундный ресинк часов.** `set_date_time` принимает только `HH_MM_SS` — гранулярность 1 секунда (доказано на OpenAPI + повторено старым репо). Значит TC-треки разных камер на стоке по USB не выровнять точнее ~1 с, и «обрезка по таймкоду» между камерами на стоке не работает.
2. **Следствие для ±1 кадра на стоке**: старт = одновременный USB-триггер всем камерам (fan-out потоками, Barrier-паттерн старого репо); выравнивание на посте = **по аудио** (клап/хлопушка в начале дубля; общий звук площадки слышат все камеры) и/или общей вспышке. E1 сейчас измеряет, какой разброс даёт USB-триггер — это ключевое число стратегии.
3. **Правильный путь к ms-ресинку ПО КАБЕЛЮ = GoPro Labs «Command Shell via USB Comms».** Labs позволяет слать команды Command Language (включая `oT` с миллисекундами и `!S` отложенный старт) прямо по USB — без всяких QR. Если подтвердится на HERO13 (TODO-verify после установки Labs) — получаем: точные часы всех камер по кабелю → честные TC-треки → обрезка по TC + `!S`-старт по расписанию часов, USB-джиттер уходит из уравнения. **Это усиливает кейс Labs** (docs/labs-case.md) — теперь Labs не «желательна», а главный кандидат на продакшн-механизм площадки.
4. **QR-генератор (src/qr_time.py) остаётся** как лабораторный инструмент Фазы 0/1: измерить оффсет «QR→камера», сверить TC-канал, калибровать стенд. На площадке не используется.
5. Субкадровая фаза (1/10–1/100) — без изменений: она в принципе не задаётся ни QR, ни USB — только измеряется (LED/полосы/аудио) и компенсируется на посте.

## Обновлённый порядок приоритетов Фазы 0/1

E1 (джиттер USB-триггера) → E4 (аудио-канал = основной пост-инструмент стока) → Labs-трек: установка + **проверка Command Shell via USB** (`oT` по кабелю, `!S`) → сравнение распределений старта «HTTP-триггер vs `!S`-по-часам».
