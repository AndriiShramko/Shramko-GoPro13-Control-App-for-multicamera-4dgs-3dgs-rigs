# Один визит оператора — всё, что нужно физически (батч ~10 минут)

Агент ждёт и продолжит сам после каждого пункта (вахта на появление камеры уже стоит).

## 1. Драйвер (ОБЯЗАТЕЛЬНО, без этого эксперименты не начнутся, ~2 мин)

Win+X → Диспетчер устройств → **«CDC NCM»** (жёлтый значок, в «Другие устройства») → ПКМ «Обновить драйвер» → «Найти драйверы на этом компьютере» → «Выбрать драйвер из списка» → класс **Сетевые адаптеры** → **Microsoft → UsbNcm Host Device** → Далее → согласиться с предупреждением.
Запасной вариант: установить GoPro Webcam utility из официальной статьи (скачивается только вручную из браузера). Детали: `docs/session-logs/2026-07-12-E0-connectivity-gate.md`.

## 2. Направить камеру на монитор (~2 мин)

Поставить/закрепить HERO13 так, чтобы она видела ЦЕНТР основного монитора с расстояния ~0.5–1 м, горизонтально, USB не в натяг. В центре экрана будет полоса из квадратов и бегущий бар — они должны попадать в кадр целиком. Агент сам проверит кадрирование первым клипом и скажет, если надо подвинуть.

## 3. Для аудио-эксперимента E4 (по сигналу агента, ~3 мин)

По инструкции на экране: 20 хлопков ладонями подряд (раз в ~3 с) В КАДРЕ камеры, на расстоянии ≤1 м от неё. Одна запись — один визит.

## 4. Для полосных тестов E3 (по сигналу агента, ~10 с)

Выключить верхний свет в комнате на время теста (LED-лампы мерцают 100 Гц и портят измерение).

## 5. Решение по GoPro Labs (можно словами в чат, не срочно)

«да, Labs» / «нет, позже». Кейс: `docs/labs-case.md`. Ставится в КОНЦЕ Фазы 0, руками оператора по инструкции. После находки E6 (стоковый QR-ресинк работает без Labs) — Labs желательна, но уже не критична.

## Больше ничего не нужно

SD-карту агент чистит сам (после инвентаря и скачивания с checksum). Кабель/аккум — только если камера умрёт.
