# Один sync-якорь в оптическом коде даёт ложные захваты геометрии

Первая версия полосы стенда имела только ведущий 8-битный якорь. Декодер находил sync-паттерн с НЕВЕРНЫМ размером ячейки (алиасинг) и молча декодировал мусор: селфтест 4/300 (1.33%).

**Фикс:** замыкающий инвертированный якорь после данных + перебор размеров ячейки от большого к малому. Геометрия (x0, cell) подтверждается только если сходятся ОБА якоря → селфтест 300/300.

**Как применять:** любой машиночитаемый экранный код для съёмки камерой — минимум два разнесённых якоря, валидация на синтетическом ground-truth ДО использования с камерой (headless-рендер тех же процедур рисования — дешёвый способ получить эталон).
