# Диск C: на этой машине хронически полон — captures/ живёт на E: через junction

C: был 100% полон (2.9 ГБ свободно) при старте Фазы 0 — дрейф-дубль (~4.5 ГБ) не поместился бы, а запись на переполненный системный диск роняет систему. E: имел 990 ГБ.

**Решение:** `mklink /J C:\dev\gopro-sync\captures E:\gopro-sync-captures` (junction не требует админа) — все скрипты продолжают писать в captures/ прозрачно.

**Как применять:** перед любыми видео-пайплайнами на этой машине проверять свободное место ВСЕХ дисков (`Get-PSDrive`), большие данные — только E:/G:. Чек места уже в spec-ops; junction — стандартный приём.
