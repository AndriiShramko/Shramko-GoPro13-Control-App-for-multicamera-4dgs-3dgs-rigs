# HERO13: 8:7 60fps СУЩЕСТВУЕТ (я ошибся, оператор был прав)

Я объявил «8:7 максимум 30fps» на основе своего combo-сканера (403 на 8:7@60). Оператор возразил, что он включал 8:7@60. Проверка по документации + живой клип: **оператор прав.**

**Факт (ffprobe живого клипа): 3840×3360 (=8:7) @ 59.94fps.**

Причины провала моего сканера:
1. Пробовал 5.3K 8:7 @60 — этого НЕТ (5.3K 8:7 максимум 30fps). А 4K 8:7 @60 — ЕСТЬ.
2. Неверный resolution-option: 8:7 на HERO13 = option **108** (4K 8:7 V2), НЕ 26/28 (это HERO11 → 403).

Правильно: `setting=2&option=108` → `setting=3&option=5` (или 234=5). Оба fps-setting (3 и 234) приняли 60.

**Урок: не объявлять ограничение платформы по своему автоперебору — сверять с документацией И живой камерой. Оператор с камерой в руках — источник истины.**
