# Деградировавший USB молча ОБРЕЗАЕТ скачивание (не таймлапс, не режим!)

Долго гонялся за «клипы 0.8с вместо 4с», грешил на таймлапс/режим. Диагностика: `encoding=True` все 6 с записи → камера пишет ПОЛНЫЙ клип. Файл на скачивании 1.7 МБ вместо ~100 МБ (4K60 4с) → **download обрывается**, а не запись коротка.

Причина: после многих часов (записи/ребуты/Labs-перепрошивка/сон) USB-соединение HERO13 деградирует — стрим скачивания рвётся без ошибки, отдавая truncated-файл.

**Фиксы (в wired_gopro.download):** (1) сверять размер скачанного с camera-reported size из media list; (2) ретраи при недоборе; (3) `timeout=(10,60)` connect/read раздельно. Плюс: setting 128=13 на HERO13 = НОРМАЛЬНОЕ видео (не таймлапс — старое сопоставление ID было для HERO10/11).

**Урок:** при аномально коротких/маленьких файлах — сперва проверить `encoding`-флаг ВО ВРЕМЯ записи (пишет ли камера) и сверить размер с media list, а не гадать про режим. На 100-камерном риге верификация размера скачивания ОБЯЗАТЕЛЬНА (иначе тихие битые дубли).
