# Оптический код для съёмки камерой: меняй кодировку, а не наращивай декодер

Шесть версий декодера за вечер (1.3% → 91.4% на реальном клипе) — и решением оказалась не «умная» математика, а смена КОДИРОВКИ на стороне стенда.

## Что убивало по очереди (реальная HERO13, fisheye Wide-объектива; «изогнутый экран» — моя ошибочная атрибуция, оператор поправил: панель плоская)

1. Целочисленный перебор строк/ячеек — дробный шаг (20.26px) накапливает ошибку на 40 ячейках.
2. Линейный шаг от крайних якорей — перспектива даёт ±35% локального шага (14→24px!), середина уезжает на целую ячейку.
3. Опора на структуру блобов (1-2-1) — резкий рендер НЕ сливает соседние ячейки, смаз камеры — сливает; хрупко.
4. Глобальный проективный параметр — дисторсия S-образная (fisheye объектива): левый якорь хочет k=-0.25, правый k=+0.05.
5. Global-pitch распределение (largest remainder) — длинные прогоны (24 нуля Gray-кода) внутри не имеют переходов → шаг внутри не калибруется, «валидные» ошибочные разбиения проходят якорную проверку = ТИХИЕ неверные индексы (ловится только проверкой монотонности по видео).

## Что сработало

**Манчестерская кодировка** (бит = пара ячеек 10/01) + маркеры-нарушения (3 подряд) по краям:
- максимальный прогон = 3 ячейки → локальный шаг калибруется КАЖДЫМ переходом (EMA), перспектива любой гладкой формы перестаёт быть проблемой;
- валидность пар 01/10 = встроенная контрольная сумма: сбой разбиения даёт невалидную пару → кадр отбраковывается, а не декодируется неверно;
- затравка шага из ПЕРВОГО маркера (ровно 3 ячейки по построению), не из глобального среднего.

Цена: 56 ячеек вместо 40 (×1.4 ширина). Результат: селфтест 300/300, реальный клип 160/175 (91.4%), 0 нарушений монотонности индексов.

## Правила на будущее (любые экранные коды под камеру)

- Проектируй код так, чтобы ЛЮБОЙ прогон был коротким (Manchester/бифазные кодировки), иначе локальная геометрия внутри длинных прогонов неконтролируема.
- Валидация должна ловить и НЕВЕРНЫЕ декоды, не только недекоды (самосинхронизирующиеся пары, CRC) — якорей по краям недостаточно.
- Синтетический селфтест ловит регрессии, но НЕ заменяет реальный кадр: резкость/смаз меняют структуру блобов качественно.
- Финальная проверка канала: монотонность/скорость декодированных индексов по всему клипу.
