# Железо для фазировки питанием (путь Б) + LED-строб — что купить и как собрать

**Зачем:** Labs USB Power Trigger включает камеру при подаче питания на USB. Если лаг «питание → старт сенсора» стабилен (проверим E-Б1), то, подавая питание каждой камере в рассчитанный микросекундный момент, мы ВЫСТАВЛЯЕМ фазу кадра, а не только меряем её. Механическое реле НЕ годится (дребезг/джиттер 5–10 мс = четверть кадра); нужен транзисторный ключ + микроконтроллер, который сам исполняет фронты по своему кварцу.

## Почему так агент сможет управлять

Arduino подключается к ПК обычным USB (виртуальный COM-порт). Агент шлёт текстовые команды (`P1 ON`, `P1 OFF`, `P1 AT <t_us>`, `LED PULSE <len_us>`); все фронты Arduino исполняет по СВОЕМУ таймеру (точность ~1 мкс, между каналами — единицы мкс). Прошивку и python-драйвер агент пишет и заливает сам (arduino-cli).

Готовая альтернатива без пайки — программируемый хаб **YKUSH** (per-port power по команде): проще, но джиттер переключения миллисекундный → годится для автовключения 100 камер на площадке, НЕ годится для точной фазировки в экспериментах. Для науки — Arduino.

## Схема (один канал; второй — копия на D3)

```
БП/хаб 5V ──── VBUS_in ──[MOSFET D4184: IN→OUT]──── VBUS_cam ──→ камера (красный провод USB)
                             │ GATE ← Arduino D2
D+ / D- / GND ───────────────────────── напрямую ПК↔камера (данные не рвём!)
Arduino GND ── общий GND с БП и камерой (ОБЯЗАТЕЛЬНО)
Arduino D4 ──[R 150Ω]──▶ LED ── GND      (строб в поле зрения камер)
Arduino USB ──→ ПК (COM-порт, управление агентом)
```

Важно: рвём ТОЛЬКО +5V (VBUS). Данные и земля сквозные — камера остаётся видна ПК по NCM, когда питание подано. Земля общая у всех устройств.

## Протокол (агент реализует)

`SYNC` → Arduino отвечает своим micros() (калибровка часов ПК↔Arduino по round-trip, ±0.5 мс — для АБСОЛЮТНОЙ привязки; между каналами точность = кварц Arduino, ~мкс);
`P1 AT <us>` / `P2 AT <us>` — подать питание канала в момент по часам Arduino;
`P1 OFF`; `LED AT <us> LEN <us>` — строб заданной длительности (для полос RS — 100–500 мкс).

## Эксперименты, которые это железо открывает

- **P-Б1**: 20× (power OFF → ON в момент T → камера бутится (Labs Power Trigger) → запись → фаза кадра по стенду/LED) → σ лага «питание→фаза». σ < 3 мс → фазировка жизнеспособна; σ > 10 мс → путь Б закрыт, остаётся путь А.
- **LED-строб**: полосы rolling shutter → измерение фазы с σ 0.3–0.5 мс (1/100 кадра @30fps) — независимо от пути Б.
- Масштаб на 100 камер (если Б взлетит): тот же принцип — MCU + сдвиговые регистры/драйверы на 100 MOSFET-каналов (плата ~300–500 zł деталями), одна команда — 100 фронтов по расписанию.
