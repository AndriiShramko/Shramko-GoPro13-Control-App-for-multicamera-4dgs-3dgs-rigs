# Inline-модуль VBUS на каждую GoPro: своя мини-плата (ресёрч 2026-07-12, даташиты в конце)

## Ответ на требования Андрия

- ✅ Микро-устройство в разрыв кабеля (не хаб-коробка) — плата ~1.5–2 см в термоусадке.
- ✅ Питание от того же USB (MCU от HOST-стороны VBUS через LDO).
- ✅ **Полная скорость скачивания USB3 (5 Гбит/с) сохраняется** — ключевой инсайт: SuperSpeed-пары (SSTX/SSRX) НЕ коммутируем, пропускаем ПРЯМОЙ ТРАССОЙ насквозь; режем ТОЛЬКО VBUS. Готового такого на рынке нет (только хаб-боксы YKUSH3/Acroname) → кастомная плата оправдана и электрически несложна.

## Минимальная схема

Два разъёма USB-C: J1 = HOST/питание, J2 = камера.
```
J1  SSTX±/SSRX±/D± ──прямая согласованная трасса ~90Ω──► J2   (НЕ коммутируется, полная скорость)
J1  GND, CC, SBU   ──насквозь──►                        J2
J1  VBUS ──►[LOAD SWITCH TPS22918]──EN◄──GPIO MCU──► J2.VBUS   (ЕДИНСТВЕННАЯ разрезаемая цепь)
J1.VBUS(всегда жив)─►[LDO 3.3V]─►[MCU CH32V003]─►UART─►[RS-485 THVD1450]─► шина к 99 модулям
                                        └─ADC: контроль тока/напряжения VBUS камеры (опц.)
```

## Функции устройства

1. **Фазировка старта питанием**: MCU по команде подаёт VBUS в точный момент → Labs USB Power Trigger бутит+стартует камеру. Мкс-точность фронта MCU (кварц), между модулями — единицы мкс.
2. **Перевтык без человека**: разрыв VBUS → self-powered GoPro ОБЯЗАНА снять USB-терминации (спека USB, ST AN1040) → хост видит disconnect → re-enumeration. Достаточно рвать VBUS; данные рвать НЕ нужно (страховка HD3SS460 — только если тест на HERO13 покажет, что чистого VBUS-тогла мало; так делают YKUSH3/Acroname).
3. **Адресация 100 штук**: RS-485 daisy-chain (2 провода A/B+GND), Modbus-подобные адреса — один хост рулит всеми.

## Честная оговорка (важно для целей проекта)

USB Power Trigger стартует камеру по загрузке (~секунды, с джиттером) → это ГРУБАЯ фазировка старта 100 камер, НЕ покадровый генлок. **Управляет ли момент подачи VBUS ФАЗОЙ кадра сенсора — НЕ доказано** (это гипотеза «путь Б»); проверяется экспериментом E7b на 2 камерах. Если да — устройство даёт аппаратную фазировку во время съёмки. Если нет — устройство всё равно нужно для перевтыка/автовключения/staggered-boot 100 камер.
