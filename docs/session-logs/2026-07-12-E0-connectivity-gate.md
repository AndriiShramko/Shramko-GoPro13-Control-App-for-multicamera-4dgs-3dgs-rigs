# E0 connectivity-gate — 2026-07-12: NO-GO (драйвер), диагноз полный

## Статус: камера жива, канал заблокирован отсутствием NCM-драйвера. Нужен ОДИН админ-визит оператора (~2 мин).

## Факты (все — из живых команд этой сессии)

1. **Камера подключена и в правильном режиме.** `Get-PnpDevice` видит композит USB `VID_2672&PID_0059`, серийник `C3531325121539`:
   - `USB Composite Device` — OK
   - `HERO13 Black` (WPD/медиа) — OK
   - `CDC NCM` (сетевой интерфейс управления) — **Error, ProblemCode 28** («драйверы не установлены»)
2. **Инбокс-драйвер Windows не привязывается by design.** `C:\Windows\INF\usbncm.inf` матчит только `USB\MS_COMP_WINNCM`; универсальная строка `USB\Class_02&SubClass_0d&Prot_00` в inf ЗАКОММЕНТИРОВАНА. Камера репортит только class-ID.
3. **Камера не заявляет MS-OS-дескрипторы**: `HKLM\...\UsbFlags\267200590001\osvc = {0,0}` → автопривязка невозможна в принципе, это не кэш-глюк.
4. **Пакет инбокс-драйвера в системе ЕСТЬ**: `DriverStore\FileRepository\usbncm.inf_amd64_9957a38c3d2283ed` → ручная привязка возможна.
5. **GoPro-драйвер (GoPro UsbNcm Host Device)** отсутствует в DriverStore, отсутствует в Microsoft Update Catalog (проверено: только Karma 2016). Официальный носитель — установщик GoPro Webcam utility; его хостинг (gopro.my.salesforce.com, ссылки из статьи GoPro-Webcam) отдаёт файл только интерактивному браузеру (Lightning-сессия) — curl/автоматизация получают HTML-заглушку. Сторонние зеркала (uptodown/filehippo/softpedia) отвергнуты — недоверенный источник.
6. Шелл агента не элевирован; `pnputil /restart-device` → Access denied. Любая привязка драйвера требует админа.
7. Ожидаемый IP камеры после драйвера: **172.25.139.51** (serial → 5,3,9... последние 3 цифры `539`), хост получит `.54`.

## ЧТО СДЕЛАТЬ ОПЕРАТОРУ (вариант A — рекомендуемый, ~2 мин, ничего не скачивать)

1. Win+X → «Диспетчер устройств» (Device Manager).
2. Найти устройство **«CDC NCM»** с жёлтым восклицательным знаком (обычно в «Другие устройства»).
3. ПКМ → «Обновить драйвер» → «Найти драйверы на этом компьютере» → **«Выбрать драйвер из списка доступных»**.
4. Выбрать класс **«Сетевые адаптеры»** → производитель **Microsoft** → модель **«UsbNcm Host Device»** → Далее.
5. Согласиться с предупреждением о совместимости (это стандартный CDC NCM — Linux-драйвер того же класса работает с HERO13 из коробки).
6. Готово, если в «Сетевых адаптерах» появился адаптер и `ipconfig` показывает подсеть `172.25.139.x`.

## Вариант B (если A не взлетит)

В СВОЁМ браузере открыть статью GoPro Webcam (community.gopro.com → статья «GoPro Webcam Information And Troubleshooting») → секция Windows → «Download the GoPro Webcam desktop utility here» → установить (несёт драйвер «GoPro UsbNcm Host Device»). После установки перезоткнуть USB камеры.

## После любого варианта

Агент продолжит E0 сам: ping 172.25.139.51 → wired_usb?p=1 → /state → запись 5 с → download. Ничего дополнительно делать не нужно.

## Примечание

В UsbFlags есть и след `26720056` — к этой машине ранее подключалась другая GoPro (PID_0056), тоже без драйвера. Проблема не нова для этой машины.
