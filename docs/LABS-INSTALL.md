# Установка GoPro Labs на HERO13 — инструкция оператору (~5 минут)

**Решение принято: ставим Labs.** Прошивка скачана официально (gopro.github.io/labs → v2.10.70) и лежит в `E:\dev\gopro-sync\captures\labs-firmware\LABS_HERO13_2_10_70.zip` (агент проверит целостность и распакует, когда скачается полностью).

## Шаги (нужен кардридер)

1. Выключи камеру, вынь SD-карту, вставь в кардридер компьютера.
2. Скажи агенту «SD вставлена» — он сам распакует прошивку в корень карты (папка `UPDATE`) и проверит файлы. (Или вручную: распаковать zip так, чтобы в корне карты была папка `UPDATE`.)
3. Безопасно извлеки карту, вставь в камеру, закрой крышку.
4. Включи камеру кнопкой — она сама увидит `UPDATE` и прошьётся (мигает, перезагружается, ~3-5 мин). НЕ трогать до окончания.
5. Подключи USB обратно. Агент проверит версию (`/gopro/camera/info` → fw с суффиксом Labs) и продолжит.

## Зачем (кратко)

- **Мс-часы ПО КАБЕЛЮ** (Command Shell via USB → команда `oT` с миллисекундами) — единственный путь точного ресинка 100 камер без QR.
- **`!S` отложенный старт** по часам камеры — убирает джиттер HTTP-команды из старта.
- **TCAL** — калибровка хода часов per-camera (наши ppm из E2 станут корректируемыми).
- **USB Power Trigger** — автостарт камеры при подаче питания (и кандидат для управления ФАЗОЙ кадра моментом включения — путь Б из phase-control-research.md).

## Откат

Labs официальная и обратимая: стоковая прошивка ставится тем же способом (файл с gopro.com/update). Настройки камеры перед прошивкой снапшотятся агентом автоматически.
