# HERO13 video modes: 8:7 и 60fps — ТОЧНЫЕ ID (ресёрч по докам 2026-07-12)

## Оператор прав: 8:7 60fps СУЩЕСТВУЕТ — но только в 4K, не в 5.3K

| Разрешение | Соотношение | fps | 60fps? |
|---|---|---|---|
| **5.3K** | **8:7** | 30/25/24 | **НЕТ** (потолок 30) |
| **4K** | **8:7** | **60/50/30/25** | **ДА** |
| 5.3K | 16:9 | 60/50/30/25/24 | да |
| 4K | 16:9 | 120/100/60/50/30/25/24 | да |
| 2.7K | 16:9 | 240/200 | — |
| 1080 | 16:9 | до 240 | да |

Мой сканер провалил 8:7@60 по двум причинам: (1) пробовал 5.3K 8:7 @60 (невалидно); (2) для 4K 8:7 — правильный option **108** (4K 8:7 V2), а НЕ устаревшие 26/28 (это HERO11 → 403 на HERO13).

## Точные ID (из openapi.json, фильтр HERO13 Black)

- **Setting 2 (Video Resolution)**: `108` = 4K 8:7 V2, `107` = 5.3K 8:7 V2, `1` = 4K, `100` = 5.3K. ⚠️ НЕ `26/28` (HERO11).
- **Setting 3 (Frames Per Second)**: `5` = 60. (value=5, не «60».) Прочие: 0=240,1=120,2=100,6=50,8=30,10=24,13=200.
- **Setting 108 (Video Aspect Ratio)**: `3` = 8:7.
- ⚠️ Противоречие в ID для fps между источниками: ранний ресёрг указал setting **234**, docs-агент — setting **3**. Проверить на камере ОБА (state покажет, какой реально применился) — TODO при живой камере.

## Валидная последовательность 4K 8:7 60fps

```
GET /gopro/camera/presets/set_group?id=1000   # видео-группа
GET /gopro/camera/setting?setting=2&option=108  # 4K 8:7 (несёт соотношение)
GET /gopro/camera/setting?setting=3&option=5     # 60fps (или setting=234 — проверить)
```
Порядок: разрешение ПЕРЕД fps (смена разрешения подрезает список валидных fps). При 403 — запросить у камеры актуальные capabilities в текущем состоянии, не полагаться на полный enum спеки.

## Genlock: подтверждено — у HERO13 НЕТ

Полная проверка Labs (control/extensions) + openapi + спеки: **нет genlock, нет sensor/shutter/frame sync, нет синхро-входа/выхода**. Только синхра ЧАСОВ/таймкода (Quik wireless TC, GPS sync, LTC, QR+TCAL) — это метаданные времени, НЕ фаза экспозиции. GoPro официально прекратила 3D/genlock с HERO4+. → аппаратная межкадровая синхра на HERO13 возможна ТОЛЬКО через фазировку питанием (путь Б, недоказано), иначе — невозможна в принципе.
