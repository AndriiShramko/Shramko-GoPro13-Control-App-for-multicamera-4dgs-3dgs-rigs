# Разовая настройка «драйвер больше не требует человека» (1 клик UAC, навсегда)

## Почему одно действие всё-таки нужно от тебя

Я в группе Администраторов, НО Windows-UAC на этой машине (`ConsentPromptBehaviorAdmin=5`, `EnableLUA=1`) требует интерактивного подтверждения на любое повышение прав. Тихо повыситься можно только malware-техниками (fodhelper/подмена реестра) — я их НЕ использую (это методы атаки и неправильное решение). Легальный путь: ты ОДИН раз регистрируешь elevated-задачу; после этого я триггерю её сам сколько угодно раз БЕЗ запросов UAC.

## Что сделать (один раз, ~20 секунд)

Открой **PowerShell от администратора** (ПКМ на «Пуск» → «Терминал (Администратор)» / «Windows PowerShell (администратор)») и вставь ОДНУ команду:

```powershell
$act = New-ScheduledTaskAction -Execute "powershell.exe" -Argument "-NoProfile -ExecutionPolicy Bypass -File E:\dev\gopro-sync\tools\rebind_ncm.ps1"
$prin = New-ScheduledTaskPrincipal -UserId "$env:USERNAME" -RunLevel Highest -LogonType Interactive
Register-ScheduledTask -TaskName "GoProNcmRebind" -Action $act -Principal $prin -Force
```

Всё. Задача `GoProNcmRebind` зарегистрирована с полными правами.

## Что дальше делаю Я (без тебя)

Когда NCM-драйвер снова отвалится, я выполняю (обычными правами, без UAC):
```
schtasks /run /tn GoProNcmRebind
```
Скрипт elevated: disable→enable устройства (ре-применяет привязку) → при неудаче форс-инсталл инбокс-драйвера → лог в `%TEMP%\ncm_rebind.log`. Камера возвращается на HTTP сама.

## Альтернатива (ещё надёжнее, тоже разово)

Установить **GoPro Player** или **GoPro Webcam** из Microsoft Store / офиц. сайта — они ставят подписанный драйвер «GoPro UsbNcm Host Device», который матчит камеру по VID 2672 и привязывается АВТОМАТИЧЕСКИ при каждом подключении, даже после $SHEL-переключений. Тогда rebind-задача вообще не понадобится. (Store-установка тоже требует твоего клика.)

## И главное — я убрал корень проблемы

Драйвер отваливался КАЖДЫЙ раз, когда Я переключал камеру в serial-режим ($SHEL). Я больше НЕ переключаю режимы в рабочем цикле (доказал, что мс-часы по кабелю работают — этого достаточно, повторять не нужно). Обычная работа (HTTP + QR-время) привязку драйвера НЕ трогает. Так что интеррапты и без задачи должны прекратиться; задача — страховка на редкий случай.
